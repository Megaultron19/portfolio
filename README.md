# Harshit Singh — Portfolio

Personal portfolio: a single `index.html` with no build step.

- **Hero:** a quiet blood-moon eclipse.
- **Hidden sky:** move the cursor to light up the winter sky of 19 January (Capricornus, Orion, Taurus, Gemini, Canis Major). Find all five.
- **Sections:** overview with live GitHub activity, experience, projects, toolkit, education and contact.

Open `index.html` in a browser, or publish with GitHub Pages (Settings → Pages → deploy from branch, root folder).

`templates/` holds the design explorations this site was picked from (`templates/index.html` is the gallery).
